  • 학생 맞춤형 문제 생성 시스템

Gemini (Google)

자료 통합과 멀티모달 기반 수업 지원 도구

✓ 강점

  • 타사 대비 4배 빠른 초고속 응답
  • Google Docs, Gmail 완벽 연동
  • 100만 토큰 처리 능력
  • 넉넉한 무료 티어 가성비

✗ 약점

  • Google 생태계 의존성
  • 복잡한 코딩 구현 시 열세
  • 무료 플랜 제약 존재
  • 외부 앱 통합 제한적

교육 활용 예시

  • 회의록·수업자료 자동 요약
  • Google Docs·Sheets 기반 활동지 구성
  • 영상·이미지·텍스트 통합 수업자료 제작

Claude (Anthropic)

정교한 추론과 고품질 학습 설계 도구

✓ 강점

  • 최고의 프로그래밍 역량 보유
  • Claude Code의 터미널 자율 제어
  • 환각이 극히 적은 치밀한 논리 추론
  • 로컬 환경 직접 접근성

✗ 약점

  • 비개발자 진입 장벽 높음
  • API 환경 구축 시 높은 토큰 비용
  • 멀티모달 기능 한정적
  • 플러그인 생태계 미흡

교육 활용 예시

  • 서술형 평가 문항 개발
  • 단계별 피드백 시스템 설계
  • 학생 오답 유형 분석 및 개별화 지도

Canva AI

시각적 완성도를 높이는 디자인 특화 도구

✓ 강점

  • 코딩 지식 없이 전문가급 제작 가능
  • 평면 AI 이미지를 네이티브 레이어로 해체
  • 브랜드 키트 적용 및 다국어 번역
  • 직관적 인터페이스

✗ 약점

  • 장문 논리 구축 역량 부재
  • 범용 문서 작성 및 백엔드 코딩 불가
  • Ultra AI 크레딧 병목 현상
  • 대용량 텍스트 처리 어려움

교육 활용 예시

  • 수업용 활동지 디자인
  • 학급 안내 자료 및 카드뉴스 제작
  • 시각 중심 프로젝트 결과물 제작
