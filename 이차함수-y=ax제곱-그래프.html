Q1. a 의 부호에 따라 그래프의 모양은 어떻게 달라지나요?
a > 0 이면 아래로 볼록(∪ 모양), a < 0 이면 위로 볼록(∩ 모양)합니다. 모두 y축을 축으로 하고 원점을 꼭짓점으로 하는 포물선입니다.
Q2. |a| 가 커지면 그래프의 폭은 어떻게 되나요?
|a| 가 클수록 폭이 좁아집니다. 같은 x 에 대해 함숫값의 절댓값이 커지므로 그래프가 y축에 더 바짝 붙습니다. (|a| 가 작을수록 폭이 넓어집니다.)
Q3. y=2x2 과 y=−2x2 처럼 부호만 다른 두 그래프는?
x축에 서로 대칭입니다. 색이 같은 실선과 점선을 확인해 보세요.

공책 정리

왼쪽 카드 0 / 4 를 모두 펼치면 공책 정리가 나타납니다.

  1. y축을 축으로 하고, 원점 (0, 0)을 꼭짓점으로 하는 포물선이다.
  2. a > 0 일 때 아래로 볼록, a < 0 일 때 위로 볼록하다.
  3. |a| 가 클수록 그래프의 폭이 좁아진다.
  4. 이차함수 y = −ax2 의 그래프와 x축에 서로 대칭이다.
